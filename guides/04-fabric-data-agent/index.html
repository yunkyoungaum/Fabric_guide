Fabric Data Agent 가이드

자연어로 데이터를 묻고 답을 얻는 Data Agent — 개념부터 생성·구성, 데이터 소스 연결, 지침 튜닝, 소비 채널까지 정리합니다.

작성 중(Draft) — 아래는 이 가이드에서 다룰 목차 틀입니다.

1. Data Agent란

  • 자연어 → 질의(NL2SQL/NL2KQL) → 답변 흐름
  • 사용 시나리오와 기대 효과
  • 사전 요건: 테넌트 설정 활성화·용량·권한(→ 01. 온보딩)

2. Data Agent 생성

  • 생성 절차와 기본 구성(작성 예정)
  • 이름·설명·범위 설정

3. 데이터 소스 연결

  • 연결 가능한 소스: Lakehouse · Warehouse · Semantic Model · KQL Database
  • 소스별 특징과 선택 기준
  • 온톨로지와 연계했을 때의 이점(→ 03. 온톨로지)

4. 정확도 높이기 — 지침 · 예제 튜닝

  • 에이전트 지침(Instructions) 작성 요령
  • 예제 질의/응답(Example queries)로 성능 개선
  • 용어·별칭 정의와 모호성 해소
  • 검증 루프와 반복 개선

5. 소비(Consumption) 채널

  • Fabric 내 Copilot에서 사용
  • Teams·외부 앱 연동
  • 프로그래밍 방식(API/SDK) 호출

6. 운영 · 거버넌스

  • 권한과 데이터 접근 경계
  • 모니터링·비용 관점
  • 모범 사례와 주의점
