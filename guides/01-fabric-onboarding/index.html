Microsoft Fabric 온보딩 가이드

Capacity 생성부터 Workspace 구성, 테넌트 기능 활성화, 역할·권한 설계까지 — Fabric를 처음 도입하는 팀을 위한 온보딩 체크리스트.

작성 중(Draft) — 아래는 이 가이드에서 다룰 목차 틀입니다. 각 섹션의 상세 내용은 순차적으로 채워집니다.

1. 사전 준비 (Prerequisites)

  • Microsoft Entra(테넌트)와 조직 계정 요건
  • 필요한 라이선스 개관 — Fabric(F SKU) vs Power BI Premium(P SKU) vs 무료 체험(Trial)
  • 관리자 역할: Fabric 관리자 / 용량 관리자 / 테넌트 관리자의 구분

2. Fabric Capacity 생성

  • Capacity(용량)란 무엇인가 — CU(Capacity Unit)와 과금 모델
  • SKU 선택 기준: F2 ~ F2048, 워크로드별 권장 시작점
  • Azure Portal에서 Fabric Capacity 프로비저닝(리소스 그룹·리전 선택)
  • 일시 중지(Pause)/재개(Resume)와 비용 절감, Autoscale·Smoothing 개념
  • 체험(Trial) 용량으로 먼저 검증하기

3. Workspace 생성 및 용량 할당

  • Workspace 생성과 Capacity 바인딩
  • Workspace 역할: Admin · Member · Contributor · Viewer
  • 도메인(Domains)과 워크스페이스 구성 전략(팀·프로젝트·환경 분리)
  • OneLake와 워크스페이스의 관계

4. 테넌트 설정 — 기능 활성화

온톨로지, Data Agent, Copilot 등 신규 기능은 테넌트 관리 설정에서 명시적으로 켜야 합니다.

  • 관리 포털 → 테넌트 설정 접근 경로
  • Copilot 및 AI 기능 활성화(용량 요건 포함)
  • Data Agent(데이터 에이전트) 생성 허용 설정
  • 온톨로지 관련 미리 보기(Preview) 기능 활성화
  • 보안 그룹 기반 단계적 배포(파일럿 → 전사)

5. 권한 · 거버넌스 설계

  • 역할 기반 접근(RBAC)과 아이템 수준 권한
  • OneLake 데이터 접근 권한과 공유 모델
  • 민감도 레이블(Sensitivity Label)과 데이터 보호
  • 감사 로그와 모니터링

6. 온보딩 체크리스트
